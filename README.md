# Triple A Super Chatbot

A retrieval-augmented chatbot that answers advisers' questions about superannuation
fund documents. Django + Django REST Framework backend, hybrid (dense + BM25)
retrieval on Pinecone with a BGE reranker, answers generated by a local Ollama model,
and a single-page UI (`mvp_demo/index.html`) with per-adviser sign-in.

## Layout

    mvp_demo/
      config/          Django settings, URLs, WSGI
      rag_api/         API: chat, sign-in, users/funds, document upload + ingestion
      chunking/        PDF text/table extraction, header- and layout-based chunking, TOC filtering
      ocr_solution.py  PaddleOCR path for scanned PDFs
      ingest.py        Offline CLI that chunks PDFs and loads them into Pinecone
      bm25_encoder.json  Fitted BM25 encoder, loaded at startup
      index.html       Front end, served at /
    deploy/            EC2 deployment (systemd, nginx, TLS, DuckDNS) - see deploy/README.md

## Running locally

    cd mvp_demo
    python3.12 -m venv .venv && source .venv/bin/activate
    pip install -r requirements.txt
    cp secrets.env.template secrets.env    # fill in the Pinecone keys; DJANGO_DEBUG=True for local
    python manage.py migrate               # creates db.sqlite3, seeds advisers and funds
    ollama pull qwen3:1.7b                 # or set OLLAMA_MODEL
    python manage.py runserver

Open http://localhost:8000.

Without `DJANGO_SECRET_KEY`, settings fall back to an insecure development key -
always set it outside local development.

## Ingesting documents

Fund documents are confidential and are not in this repository. Place them in a
`pdfs/` folder next to `mvp_demo/` (ignored by git), adjust the document list at the
top of `mvp_demo/ingest.py`, then run `python ingest.py` from `mvp_demo/`. Scanned PDFs
need PaddleOCR:

    python -m pip install paddlepaddle==3.3.0 -i https://www.paddlepaddle.org.cn/packages/stable/cpu/
    python -m pip install "paddleocr[all]"

Documents can also be uploaded through the app when `DOCUMENT_UPLOADS_ENABLED` is set.
